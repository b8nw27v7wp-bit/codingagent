## 枚举思想：把所有可能都试一遍

遇到问题没思路？最简单可靠的方法就是**枚举**：把每种可能都试一次，看哪个符合条件。

> 就像找钥匙：不知道在哪，就挨个抽屉翻，总能找到。

---

## 例 1：判断质数

质数 = 只能被 1 和它本身整除的数。枚举 2 到 n-1 的所有数，看有没有能整除 n 的：

```python
def is_prime(n):
    if n < 2:
        return False
    for i in range(2, n):      # 枚举所有可能的因子
        if n % i == 0:
            return False
    return True

print(is_prime(17))   # True
print(is_prime(15))   # False
```

**优化**：其实只需要试到 √n 就够了（因为因子成对出现）。`range(2, int(n ** 0.5) + 1)` 可以把速度提升一个量级。

---

## 例 2：完美数

完美数 = 所有真因子（除自身外）之和等于它本身。例如 6 的因子 1+2+3 = 6。

```python
def is_perfect(n):
    total = 0
    for i in range(1, n):       # 枚举 1 到 n-1
        if n % i == 0:          # i 是因子
            total += i
    return total == n

print(is_perfect(6))    # True（1+2+3=6）
print(is_perfect(28))   # True（1+2+4+7+14=28）
print(is_perfect(12))   # False（1+2+3+4+6=16）
```

---

## 枚举的适用范围

枚举适合**数据规模小**的问题，因为它通常很慢（往往是 O(n²) 甚至更差）。数据量大时要换思路——但先写出**正确的**枚举版本，再优化，是工程上的常用策略。

## 关键要点

- 枚举 = 遍历所有可能，逐个验证
- 适合小规模问题，是"保底方案"
- 注意用数学性质优化（如质数只试到 √n）
