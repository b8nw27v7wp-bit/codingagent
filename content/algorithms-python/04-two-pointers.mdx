## 双指针思想

用**两个指针**（下标）同时从不同位置移动，代替嵌套循环，常能把 O(n²) 降到 O(n)。

> 就像两个人在一根绳子上从两端往中间走，边走边检查，比一个人来回跑快得多。

---

## 例 1：回文判断

判断字符串正着读和倒着读是否一样：

```python
def is_palindrome(s):
    left, right = 0, len(s) - 1   # 左右两个指针
    while left < right:
        if s[left] != s[right]:   # 两端字符不同
            return False
        left += 1                 # 左指针右移
        right -= 1                # 右指针左移
    return True

print(is_palindrome("racecar"))   # True
print(is_palindrome("hello"))     # False
```

**复杂度**：O(n)，一次遍历搞定；如果用嵌套循环，需要 O(n²)。

## 例 2：有序数组两数之和

给定**升序**数组和目标值，找两数之和等于目标：

```python
def two_sum(nums, target):
    left, right = 0, len(nums) - 1
    while left < right:
        s = nums[left] + nums[right]
        if s == target:
            return [left, right]      # 找到
        elif s < target:
            left += 1                 # 和太小，左边前进
        else:
            right -= 1                # 和太大，右边后退
    return [-1, -1]

print(two_sum([1, 2, 3, 4, 6], 7))   # [2, 3]（3+4=7）
print(two_sum([1, 2, 3], 9))         # [-1, -1]
```

**为什么正确？** 因为数组有序：和太小只能让左指针右移（变大），和太大只能让右指针左移（变小），不会漏掉答案。

## 双指针的常见形态

| 形态 | 场景 | 例子 |
|---|---|---|
| 左右向中间 | 有序数组、回文 | 两数之和、回文判断 |
| 快慢指针 | 链表、环检测 | 快慢追赶 |
| 同向双指针 | 滑动窗口 | 子数组问题 |

## 关键要点

- 双指针用两个下标协同工作，替代嵌套循环
- 适用于**有序**数据或回文类问题
- 常用复杂度：O(n)
