## 算法是什么？

**算法（Algorithm）** 就是解决问题的一系列**明确步骤**。

> 想象一本菜谱：做红烧肉需要"切肉 → 焯水 → 炒糖色 → 炖煮 → 收汁"。这些步骤就是烹饪的算法。计算机算法同理，只不过执行者是电脑。

---

## 算法的五个特征

| 特征 | 说明 | 例子 |
|---|---|---|
| 有穷性 | 必须在有限步内结束 | 不能无限循环 |
| 明确性 | 每一步含义清楚 | "加一点盐"不够明确 |
| 可行性 | 每一步都能执行 | 不能要求"飞起来" |
| 输入 | 可以有零个或多个输入 | 数组、数字 |
| 输出 | 至少有一个输出 | 结果、答案 |

## 用算法描述"找最大值"

假设有三个数，想找出最大的。步骤：

```
1. 假设第一个数是最大值 max
2. 依次拿后面的数和 max 比较
3. 如果某个数比 max 大，就更新 max
4. 输出 max
```

写成代码：

```python
nums = [5, 3, 8]
max_value = nums[0]          # 第 1 步
for n in nums[1:]:           # 第 2 步
    if n > max_value:        # 第 3 步
        max_value = n
print(max_value)             # 第 4 步 → 8
```

## 同一问题，不同算法

求 `1 + 2 + ... + 100`：

**算法 A：逐个相加**（循环 100 次）

```python
total = 0
for i in range(1, 101):
    total += i
print(total)
```

**算法 B：等差公式**（1 步算出）

```python
print(100 * (1 + 100) // 2)
```

两个算法结果一样，但 B 更快 —— 这就是下一课要学的"算法效率"。
