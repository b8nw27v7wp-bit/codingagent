## 贪心思想

**贪心算法**：每一步都做**当前看起来最好**的选择，不回头、不后悔，期望最终得到全局最优。

> 就像爬山，每走一步都选最陡的方向，希望最快登顶 —— 但有时先缓坡绕行反而更快（所以贪心不一定对）。

---

## 例：找零钱（硬币 1/5/10/25）

用**最少的硬币数**凑出指定金额。贪心策略：每次优先用**面值最大**的硬币：

```python
coins = [25, 10, 5, 1]      # 从大到小

def min_coins(amount):
    count = 0
    for c in coins:
        count += amount // c   # 能用几张最大面值
        amount %= c            # 剩余金额
    return count

print(min_coins(36))   # 25+10+1 → 3
print(min_coins(47))   # 25+10+10+1+1 → 5
```

**为什么贪心在这里正确？** 因为 25 是 5 的倍数、10 是 5 的倍数…… 大面值总能替换多个小面值。但注意：**如果硬币面值是 1/3/4，凑 6 用贪心（4+1+1=3 枚）就不是最优**（3+3=2 枚）——所以贪心需要证明，不是拿来就用。

## 例：尽可能多地装物品

背包容量固定，每件物品重量不同、价值相同。贪心：先装**最轻**的，才能装最多件：

```python
def max_items(capacity, weights):
    weights.sort()           # 最轻的优先
    count = 0
    for w in weights:
        if w <= capacity:    # 装得下就装
            capacity -= w
            count += 1
        else:
            break
    return count

print(max_items(10, [3, 5, 2, 8, 1]))   # 1+2+3=6 ≤10，加5就超 → 3 件
```

## 贪心的使用步骤

1. 确定**局部最优策略**（如"每次选最大面值"）
2. 用例子验证是否符合直觉
3. 证明或说明为什么局部最优 = 全局最优
4. 实现

## 关键要点

- 贪心 = 每步选当前最优，不回溯
- 典型应用：找零、活动安排、装物品
- ⚠️ 贪心**不一定正确**，需要论证
