## 学习目标

- 🎯 理解程序执行时间与数据规模的关系
- 🎯 认识常见复杂度：O(1)、O(n)、O(n²)
- 🎯 学会粗略估算代码的复杂度

---

## 为什么要关心速度？

同一个任务，数据量小的时候怎么都快；数据量大时差距惊人：

| 数据量 n | O(n) 操作 | O(n²) 操作 |
|---|---|---|
| 10 | 10 次 | 100 次 |
| 1000 | 1000 次 | 1,000,000 次 |
| 1,000,000 | 100 万次 | 1 万亿次 😱 |

**O(n²) 在 n 大时几乎不可用** —— 这就是为什么要学更聪明的算法。

---

## 什么是大 O 表示法

**大 O** 描述"操作次数随数据规模 n 增长的趋势"，忽略常数：

- `O(1)` — 常数时间：无论数据多大，都只做固定几步
- `O(n)` — 线性时间：数据翻倍，操作翻倍
- `O(n²)` — 平方时间：数据翻倍，操作变 4 倍

```python
# O(1)：不管列表多长，都只取第一个
def first_item(lst):
    return lst[0]

# O(n)：遍历一次列表
def find_max(lst):
    m = lst[0]
    for x in lst:        # 循环 n 次
        if x > m:
            m = x
    return m

# O(n²)：双重循环（冒泡排序就是这类）
def count_pairs(lst):
    count = 0
    for i in range(len(lst)):
        for j in range(len(lst)):   # 嵌套循环 n×n 次
            count += 1
    return count
```

---

## 怎么判断复杂度

看**循环的嵌套层数**：

| 代码结构 | 复杂度 |
|---|---|
| 无循环 / 固定次循环 | O(1) |
| 单层循环 | O(n) |
| 双层嵌套循环 | O(n²) |
| 每次循环规模减半（如二分） | O(log n) |

> 记住：循环几层，就是 n 的几次方（大概估算）。`O(log n)` 会在二分查找课详细讲。

## 小练习 🧪

下面代码的复杂度是多少？

```python
total = 0
for i in range(100):      # 固定 100 次
    total += i
```

提示：循环次数是**固定的 100**，和数据规模无关。

## 关键要点

| 复杂度 | 读法 | 例子 |
|---|---|---|
| O(1) | 常数时间 | 取第一个元素 |
| O(n) | 线性时间 | 单层循环遍历 |
| O(n²) | 平方时间 | 双层嵌套循环 |
| O(log n) | 对数时间 | 二分查找（下下节课） |
