## 冒泡排序

每轮**相邻两两比较**，大的往后交换，像气泡一样"浮"到末尾：

```python
def bubble_sort(nums):
    n = len(nums)
    for i in range(n - 1):            # 需要 n-1 轮
        for j in range(n - 1 - i):    # 每轮少比较一个
            if nums[j] > nums[j + 1]:
                nums[j], nums[j + 1] = nums[j + 1], nums[j]   # 交换
    return nums

print(bubble_sort([5, 2, 8, 1, 9]))   # [1, 2, 5, 8, 9]
```

第一轮后，最大的 9 沉到末尾；第二轮后 8 沉到倒数第二…… 每轮"锁定"一个最大数。

**复杂度**：双重循环 → O(n²)。

---

## 选择排序

每轮在剩余元素中找**最小的**，放到正确位置：

```python
def selection_sort(nums):
    n = len(nums)
    for i in range(n - 1):
        min_idx = i                    # 假设当前位置最小
        for j in range(i + 1, n):      # 在剩余部分找更小的
            if nums[j] < nums[min_idx]:
                min_idx = j
        nums[i], nums[min_idx] = nums[min_idx], nums[i]   # 交换到前面
    return nums

print(selection_sort([7, 3, 9, 1]))   # [1, 3, 7, 9]
```

第一轮找到全局最小 1 放到开头，第二轮在剩下里找最小 3……

**复杂度**：也是 O(n²)，但**交换次数**比冒泡少（每轮最多 1 次交换）。

---

## 两者对比

| 排序 | 思路 | 比较次数 | 交换次数 |
|---|---|---|---|
| 冒泡 | 相邻比较上浮 | O(n²) | 多（每步都可能换） |
| 选择 | 每轮选最小 | O(n²) | 少（每轮最多 1 次） |

数据量小（n < 1000）时两者都够用；数据量大时要用 O(n log n) 的排序（如 Python 内置 `sorted()` 就是）。

## 关键要点

- 冒泡：相邻比较交换，大数上浮/下沉
- 选择：每轮挑最小放到最前
- 都是 O(n²)，适合小数据；大规模用 `sorted()`
