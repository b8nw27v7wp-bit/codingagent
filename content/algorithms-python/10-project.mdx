## 项目背景

你要给同学做一个"数据处理工具箱"：输入一串数字，它能帮你**去重、排序、查找**。这是很多真实工具（如 Excel 的去重排序）的简化版。

---

## 需求

1. 读入一串整数
2. 去掉重复的数字
3. 从小到大排序
4. 回答：第 k 小的数字是多少

---

## 参考实现

```python
def process(nums, k):
    unique = sorted(set(nums))    # 去重 + 排序
    if k < 1 or k > len(unique):
        return "越界"
    return unique[k - 1]          # 第 k 小（下标 k-1）

nums = [3, 1, 3, 2, 1]
print(process(nums, 2))   # 去重排序后 [1, 2, 3]，第 2 小 = 2
print(process(nums, 5))   # 越界
```

**用到的算法**：
- `set()` 去重（哈希思想，O(n)）
- `sorted()` 排序（O(n log n)）
- 下标直接访问（O(1)）

## 挑战：不借助 sorted() 实现

如果你想让程序更"原生"，可以自己实现排序（用第 07 课的选择排序）：

```python
def selection_sort(nums):
    n = len(nums)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if nums[j] < nums[min_idx]:
                min_idx = j
        nums[i], nums[min_idx] = nums[min_idx], nums[i]
    return nums

nums = [3, 1, 3, 2, 1]
unique = []
for x in nums:                    # 手动去重
    if x not in unique:
        unique.append(x)
print(selection_sort(unique))     # [1, 2, 3]
```
