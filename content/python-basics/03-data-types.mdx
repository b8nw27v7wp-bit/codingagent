## Python 的四种基本类型

| 类型 | 关键字 | 例子 | 说明 |
|---|---|---|---|
| 整数 | `int` | `42`, `-7`, `0` | 没有小数点的数字 |
| 浮点数 | `float` | `3.14`, `-0.5` | 有小数点的数字 |
| 字符串 | `str` | `"hello"`, `'你好'` | 文本，用引号包起来 |
| 布尔值 | `bool` | `True`, `False` | 只有真/假两种值 |

```python
score = 98          # int — 整数
pi = 3.14159        # float — 浮点数
name = "Python"     # str — 字符串
is_pass = True      # bool — 布尔值
```

---

## 查看类型

用 `type()` 函数可以查看一个变量是什么类型：

```python
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("hello"))  # <class 'str'>
print(type(True))     # <class 'bool'>
```

## 类型转换

有时候需要把一种类型转成另一种：

```python
# str → int
age = int("18")      # "18"（字符串）→ 18（整数）

# int → str
text = str(42)       # 42（整数）→ "42"（字符串）

# str → float
price = float("9.9") # "9.9"（字符串）→ 9.9（浮点数）

# 任意类型 → bool
print(bool(0))       # False（0 转成 False）
print(bool(1))       # True（非 0 转成 True）
print(bool(""))      # False（空字符串转成 False）
```

> ⚠️ `int("abc")` 会报错！字符串必须是数字才能转成整数。

## 字符串拼接 vs 数字运算

```python
# 字符串 + 字符串 = 拼接
print("Hello" + " World")  # Hello World

# 数字 + 数字 = 数学加法
print(10 + 20)              # 30

# 这个会报错！不同类型不能直接相加
# print("年龄：" + 18)       # ❌ 错误！
print("年龄：" + str(18))   # ✅ 正确：先转成字符串
```

## f-string：更方便的字符串

```python
name = "小明"
age = 18
print(f"我叫{name}，今年{age}岁")  # 我叫小明，今年18岁
```

`f"..."` 里的 `{变量}` 会被自动替换成变量的值。

## 关键要点

| 类型 | 什么时候用 |
|---|---|
| `int` | 计数、年龄、序号 |
| `float` | 价格、分数、科学计算 |
| `str` | 名字、消息、任何文本 |
| `bool` | 是否满足条件、开关 |
