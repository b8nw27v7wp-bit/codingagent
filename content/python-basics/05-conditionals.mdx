## 生活场景

我们每天都在做判断：

```
如果 下雨了：
    带伞出门
否则：
    直接出门
```

Python 也是这样的：

```python
if weather == "rain":
    print("带伞出门")
else:
    print("直接出门")
```

## if 语句

```python
score = 85

if score >= 60:
    print("及格！")         # ← 前面空 4 格（缩进）
```

| 要素 | 说明 |
|---|---|
| `if` | 关键字：如果... |
| `score >= 60` | 条件：分数是否 ≥ 60 |
| `:` | 冒号：后面跟条件成立时要执行的代码 |
| `    print(...)` | 缩进（4 个空格）：条件成立才执行 |

> ⚠️ **缩进很重要！** 缩进告诉 Python 哪些代码属于这个 `if`。

---

## if/elif/else

多个条件分支：

```python
score = 85

if score >= 90:
    print("优秀")
elif score >= 80:        # elif = else + if
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

程序从上往下检查，**第一个满足的条件会被执行**，后面的不再检查。

## 比较运算符

| 运算符 | 含义 | 例子 |
|---|---|---|
| `==` | 等于 | `x == 5` |
| `!=` | 不等于 | `x != 5` |
| `>` | 大于 | `x > 5` |
| `<` | 小于 | `x < 5` |
| `>=` | 大于等于 | `x >= 5` |
| `<=` | 小于等于 | `x <= 5` |

> ⚠️ `=` 是赋值，`==` 是比较！这是初学者最容易犯的错。

## 逻辑运算符

```python
age = 20
has_ticket = True

# and：两个条件都成立
if age >= 18 and has_ticket:
    print("可以入场")

# or：至少一个条件成立
if age < 18 or has_ticket:
    print("需要家长陪同或持票")

# not：取反
if not has_ticket:
    print("请先买票")
```

## 小练习 🧪

x = 10
if x > 5:
    print("A")

2. 只有 `A`

## 关键要点

| 结构 | 说明 |
|---|---|
| `if 条件:` | 条件成立时执行 |
| `elif 条件:` | 上一个不成立时，再检查这个 |
| `else:` | 以上都不成立时执行 |
| 缩进 | 必须，4 个空格 |
| `==` | 比较是否相等（不是 `=`） |
