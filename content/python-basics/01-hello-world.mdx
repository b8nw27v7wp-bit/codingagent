## Python 是什么？

Python 是一门**简单易学**的编程语言。它的语法像英语一样自然，是世界上最受欢迎的编程语言之一。

> 想象你在给一个聪明的机器人下指令 —— Python 就是你跟机器人沟通的语言。

---

## 你的第一行代码

打开你的编辑器，输入下面这行代码：

```python
print("Hello, World!")
```

运行它，你会看到：

```
Hello, World!
```

**发生了什么？**
- `print()` 是一个**函数** — 它让电脑在屏幕上显示文字
- `"Hello, World!"` 是你要显示的内容 — 用双引号 `"` 包起来
- 这对括号 `()` 和引号 `""` 必须成对出现

## print() 的更多用法

```python
# 打印数字（不需要引号）
print(42)

# 打印计算结果
print(1 + 2 + 3)

# 用逗号分隔多项
print("答案是", 42)
```

## 关键要点

| 概念 | 说明 |
|---|---|
| `print()` | 在屏幕上显示内容的函数 |
| `"文本"` | 字符串，必须用引号包起来 |
| `# 注释` | 以 `#` 开头的是注释，不会被运行 |
