## 输出：print()

我们已经学过了 — 把信息显示在屏幕上：

```python
print("欢迎来到 Python 世界！")
print("1 + 1 =", 1 + 1)
```

---

## 输入：input()

`input()` 让程序**等待用户输入**，然后把输入的内容作为字符串返回：

```python
name = input("你叫什么名字？")
print(f"你好，{name}！")
```

运行效果：
```
你叫什么名字？小明
你好，小明！
```

> 📦 **生活比喻**：`input()` 就像你递给别人一张"请填写"的表格，然后等待对方填好还给你。

---

## ⚠️ 输入永远是字符串

```python
age = input("你几岁？")
print(type(age))     # <class 'str'> — 是字符串，不是数字！

# 如果要用来做数学运算，需要转换
age = int(input("你几岁？"))  # 转成整数
next_year = age + 1
print(f"明年你就 {next_year} 岁了")
```

---

## 你的第一个交互式程序

```python
# 简单的计算器
print("=== 加法计算器 ===")
a = float(input("输入第一个数字："))
b = float(input("输入第二个数字："))
result = a + b
print(f"{a} + {b} = {result}")
print("谢谢使用！")
```

## 小练习 🧪

```python
x = input("请输入：")
print(x * 2)
```

如果用户输入 `5`，输出是什么？

1. `10` — 数学计算 5×2
2. `55` — 字符串 "5" 重复两次

---

## 关键要点

| 函数 | 作用 | 返回值类型 |
|---|---|---|
| `print()` | 显示内容 | 无 |
| `input()` | 读取用户输入 | 总是 `str` |
| `int(input())` | 读取并转整数 | `int` |
