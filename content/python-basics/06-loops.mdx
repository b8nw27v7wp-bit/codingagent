Python 有两种循环：**for**（计数循环）和 **while**（条件循环）。

---

## for 循环

`for` 循环用于**已知次数**的重复操作。

```python
# 打印 1 到 5
for i in range(1, 6):
    print(f"第 {i} 次")
```

> `range(1, 6)` 生成 1, 2, 3, 4, 5（**不包含 6**！）

### range() 的三种用法

| 写法 | 含义 | 结果 |
|---|---|---|
| `range(5)` | 0 到 4 | 0, 1, 2, 3, 4 |
| `range(2, 6)` | 2 到 5 | 2, 3, 4, 5 |
| `range(1, 10, 2)` | 步长为 2 | 1, 3, 5, 7, 9 |

### for 遍历字符串

```python
for char in "Python":
    print(char)  # 逐字打印 P y t h o n
```

## while 循环

`while` 循环用于**满足条件就一直做**的情境。

```python
count = 1
while count <= 5:
    print(f"第 {count} 次")
    count = count + 1  # 别忘了更新！
```

### ⚠️ 警惕死循环！

```python
# 这段代码永远不会停止！
while True:
    print("我停不下来了...")
```

> 如果不小心写了死循环，按 **Ctrl+C** 强制停止。

## break 和 continue

| 关键字 | 作用 |
|---|---|
| `break` | 立刻跳出整个循环 |
| `continue` | 跳过本次，开始下一次 |

```python
# break 示例：找到第一个大于 5 的数
for i in range(1, 10):
    if i > 5:
        print(f"找到了：{i}")
        break

# continue 示例：跳过偶数
for i in range(1, 6):
    if i % 2 == 0:
        continue
    print(i)  # 只打印 1, 3, 5
```

## 嵌套循环

循环里面可以套循环！就像时钟的分针在时针里面转。

```python
# 打印乘法表
for i in range(1, 4):
    for j in range(1, 4):
        print(f"{i}×{j}={i*j}", end="  ")
    print()  # 换行
```

## 关键要点

| 要点 | 说明 |
|---|---|
| `for` | 已知次数用 for + range() |
| `while` | 条件满足就一直做 |
| `break` | 提前退出循环 |
| `continue` | 跳过本次，继续下一次 |
| 缩进 | 循环体必须缩进 4 个空格 |
| `range(a, b)` | **不包含 b** |
