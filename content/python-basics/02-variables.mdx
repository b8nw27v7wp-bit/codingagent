## 什么是变量？

**变量就像一个带标签的盒子**——你给盒子贴个标签（变量名），然后把东西（数据）放进去。

```python
name = "小明"    # 贴了标签 "name" 的盒子里放着 "小明"
age = 18         # 贴了标签 "age" 的盒子里放着 18
score = 95.5     # 贴了标签 "score" 的盒子里放着 95.5
```

> 🧊 **生活比喻**：冰箱里的收纳盒，每个盒子有标签：`鸡蛋`、`牛奶`、`蔬菜`。你想用哪个，就按标签取。

## 赋值 = 号

`=` 不是数学里的"等于"，而是**赋值**——把右边的值放进左边的变量。

```python
x = 10      # 把 10 放进 x
x = 20      # x 里的值变成了 20（覆盖了原来的 10）
x = x + 5   # 取出 x 的值(20)，加 5，再放回 x（现在 x = 25）
```

---

## 变量的值可以变

```python
balance = 100           # 余额 100
balance = balance - 30  # 花了 30，余额变 70
balance = balance + 50  # 存了 50，余额变 120
print(balance)          # 输出：120
```

---

## 命名规则

| ✅ 可以 | ❌ 不可以 |
|---|---|
| `age` | `18age`（不能数字开头） |
| `user_name` | `user-name`（不能用连字符） |
| `_private` | `if`（不能用关键字） |
| `中文变量` | `my var`（不能有空格） |

**推荐风格**：用小写 + 下划线，如 `student_name`、`total_score`

## 关键要点

| 概念 | 说明 |
|---|---|
| 变量 | 给数据贴标签，方便之后使用 |
| `=` | 赋值操作符，把右边的值放进左边的变量 |
| 变量名 | 不能数字开头、不能含空格、不能用关键字 |
