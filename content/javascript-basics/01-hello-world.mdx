## JavaScript 是什么？

JavaScript 是**互联网的通用语言** —— 你打开的每一个网页背后几乎都有它的身影。它最初用来让网页"动起来"，现在也能写服务器（Node.js）、手机 App、桌面软件。

> 如果把网页比作一栋房子，HTML 是**墙壁和骨架**，CSS 是**装修和油漆**，JavaScript 就是**水电和电器** —— 让一切真正"活"起来。

这门课我们使用 **Node.js** 运行 JavaScript，也就是在电脑上直接执行，不需要浏览器。

---

## 你的第一行代码

在编辑器里输入：

```javascript
console.log("Hello, World!");
```

运行它，你会看到：

```
Hello, World!
```

**发生了什么？**
- `console.log()` 是一个**函数** — 它把内容显示在控制台（终端）
- `"Hello, World!"` 是你要显示的文字 — 用双引号 `"` 或单引号 `'` 包起来
- 每条语句末尾的分号 `;` 表示"这句话说完了"（JS 里可以省略，但建议写上）

```javascript

```

## 小结

- JavaScript 能写网页、服务器、App，是 Web 开发的核心语言
- `console.log(内容)` 在控制台输出文字
- 文字（字符串）需要用引号包住
