## for 循环

需要重复做某事时用循环。`for` 循环适合"知道要循环几次"的情况：

```javascript
// 打印 1 到 5
for (let i = 1; i <= 5; i++) {
  console.log(i);
}
```

拆解一下：

```javascript
for (初始化; 条件; 更新) {
  // 循环体：条件为 true 时反复执行
}
```

- `let i = 1` — 起点：从 1 开始
- `i <= 5` — 条件：i 小于等于 5 就继续
- `i++` — 更新：每轮结束 i 加 1（等价于 `i = i + 1`）

> 执行顺序：初始化 → 检查条件 → 执行循环体 → 更新 → 再检查条件...

## 累加求和

循环最常见的用途是累加：

```javascript
let sum = 0;
for (let i = 1; i <= 100; i++) {
  sum += i;          // 等价于 sum = sum + i
}
console.log(`1 加到 100 等于 ${sum}`);   // 5050
```

## while 循环

`while` 适合"不知道循环几次，看条件"的情况：

```javascript
let count = 3;
while (count > 0) {
  console.log(`倒计时：${count}`);
  count--;           // 别忘了更新，否则死循环！
}
console.log("发射！");
```

> ⚠️ `while` 里一定要有让条件最终变为 `false` 的语句，否则会**死循环**。

## break 和 continue

- `break` — 立即跳出整个循环
- `continue` — 跳过本轮，进入下一轮

```javascript
// break：找到第一个能被 7 整除的数就停
for (let i = 1; i <= 100; i++) {
  if (i % 7 === 0) {
    console.log(`找到了：${i}`);
    break;
  }
}

// continue：跳过偶数，只打印奇数
for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) continue;
  console.log(i);    // 1 3 5 7 9
}
```

## 小结

- `for (初始化; 条件; 更新)` 适合固定次数的循环
- `while (条件)` 适合条件控制的循环，注意避免死循环
- `break` 跳出循环，`continue` 跳过本轮
- 累加求和用 `sum += i`
